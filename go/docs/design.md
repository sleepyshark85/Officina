# Go design notes

Choices in the Go core that the code alone does not explain. Concepts are in
[`ARCHITECTURE.md`](../../ARCHITECTURE.md); decisions G1…G15 in [`go.md`](../../docs/implementations/go.md).

| Choice | Why |
|---|---|
| `Agent.Stream` returns `(iter.Seq[RunEvent], func() (Result, error))`; `Agent.Run` is `Stream` without the events | G10. The two closures hold the context, so nothing stores it in a struct. The run happens inside the consumer's `range`, so the core starts no goroutine of its own; a `break` stops ranging the model's stream, which releases what it started, and the run's own context is cancelled as it returns |
| The `error` is only for misuse (blank message or context, a conversation in use); the run's outcome is the `Result` | AGT-03 and go/CLAUDE.md: model behaviour is a result, not an error |
| `Result` is one struct with a `Status`, not three types | Every result carries usage, and a struct compares with `cmp.Diff` and has a useful zero value; `Stop` and `Failure` are set only for their status |
| A reply and the messages it answers are all appended before any `ConversationAppended` is yielded | A host that stops reading after the first append still holds a valid conversation: the user message never stands without its reply |
| A cancel seen before the reply's `Finished` drops the reply, even if the model ignores the context | AGT-05: a reply cut off mid-stream is not appended. The core checks the context after every model event |
| Conversation JSON is .NET's form: a block's raw JSON is a JSON **string** (`"raw":"{…}"`) | G9 (the same format as .NET, for the shared golden files and cross-implementation resume). The raw bytes come back exactly however a store or encoder rewrites the outer JSON (indent, canonicalize, HTML-escape: all tested), so the core needs no encoder options for them. `jsontext.PreserveRawStrings(true)` matters where a block is written as a JSON value, which is the Claude adapter's request (Go S04) |
| A `Tool` is a plain struct with its handler, `func(ctx, jsontext.Value) (string, error)`; `NewTool[In, Out]` builds one from a typed function | The handler sees the input exactly as the model wrote it, once validated. A struct of exported fields is what a host can build itself, also for MCP tools (Go S11); the generic constructor is the only place `reflect` derives a schema: properties named as `encoding/json/v2` names them, required unless `omitempty`/`omitzero`, described by a `jsonschema` tag, and refused for types whose JSON has no schema in the subset (interfaces, bytes, embedded structs, `time.Duration`, types that marshal themselves) |
| `ToolKind`'s zero value is neither `Read` nor `Write` | TOOL-03: every tool declares its kind; a forgotten one would otherwise run concurrently and unaudited-first as a read |
| The tool pipeline runs on a goroutine of its own and hands its events to the run over a channel sized calls × 4 (started, approval asked and answered, finished) | The run, on the consumer's goroutine, yields them as they come while reads run concurrently. The pipeline never waits on the host, so a consumer's `break` only cancels the run's context, then the run drains the channel without yielding and waits: finished calls keep their results, the rest get "cancelled" results, and the results message is still appended (AGT-05) |
| A run makes at most 25 model calls, then stops with `IterationLimit` | AGT-03; the same bound as .NET, so a model that keeps calling tools cannot loop forever |
| The validator compares numbers as `float64` and runs `pattern` as a Go (RE2) regular expression | The reference validator in TEST-08 uses Go's `regexp` too, and RE2 is linear, so no timeout is needed. Integers beyond 2^53 lose precision in the validator only; the handler gets the original JSON |
| Audit kinds are `AuditRunStarted`…, written as `"RunStarted"`…; the JSON-lines sink writes a duration in nanoseconds | The tool events already own `ApprovalAsked` and `ApprovalAnswered`. `encoding/json/v2` has no default form for `time.Duration` and refuses `format` tags here, so the sink passes a marshaler for it |
| Model events and run events are sealed interfaces (`ModelEvent`, `RunEvent`) over small structs | A type switch reads like the contract; other packages can create the events but not add kinds |
| A retried model call is a `Retried` model event; the run drops the blocks of the failed attempt and tells the host with `ReplyRestarted` only if text had streamed | ARCHITECTURE 4.1 (a retry notice on every retry). The adapter yields each block as it completes, so a failure mid-stream can follow blocks the run already holds |
| A reply that calls tools is not appended while the run cannot run them (Go S04: no tool runs yet) | The provider rejects a `tool_use` without its result, so such a reply would break the conversation's next request. Go S05 runs the calls and appends the reply with their results |
| `claude.New(name, effort, Options)`: name and effort required, the rest optional | MDL-03: effort is never left to the model's default. `Options` holds the test seams too (`BaseURL`, `HTTPClient`), which are plain settings of the SDK client, so no interface is added for them |
| `Model.Settings()` is .NET's string word for word: `claude model=… effort=… max_tokens=… cache=5m thinking=adaptive` (cache `1h/5m` when the lifetimes differ) | Part of the prefix fingerprint: one string for both implementations lets Go S08 match .NET's fingerprint |
| Each message of a request is written as JSON by the adapter (`encoding/json/v2` with `PreserveRawStrings`, HTML and JS escaping) and sent through `param.Override`; the rest of the request is the SDK's typed params | G9: stored blocks then reach the wire byte for byte, as the SDK's encoder leaves the canonical form unchanged. The run context is a `system` message whose content is a string, as .NET sends it, so the shared golden layout applies |
| Blocks are stored in the canonical form: the accumulated block's JSON, compacted with `jsontext.Value.Compact` (escapes kept), then `<` `>` `&` U+2028 U+2029 escaped with `encoding/json`'s `HTMLEscape` | The fixed point of the SDK's encoder (Go S02); a tool call's `Input` keeps the model's own text, from the union's raw `Input` |
| Retries are the adapter's own (the SDK's are off): five attempts, `Retry-After` (seconds or a date) capped at 30 s, else 1 s doubling with jitter; any error without an API answer (network, a stream cut short) is transient | MDL-04 mid-stream too: the SDK does not retry a stream that failed after it began. The wait is a timer in the stream's own goroutine, so nothing outlives `Stream`; tests run it under `testing/synctest` |
| Error classes are sentinel errors (`ErrTransient`, `ErrAuthentication`, `ErrInvalidRequest`) wrapping the SDK's error | `errors.Is` is how Go checks a class; the run reports the text in `Result.Detail` |
